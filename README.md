# 🐾 PetNesto – Accessories Feature

The feature allows users to browse pet accessories based on different pet categories such as **Dogs, Cats, Birds, Fish, Hamsters, Rabbits, and Turtles**.

## Features

* Pet-wise accessory categories
* Product browsing interface
* Search functionality
* Responsive design
* Cart and wishlist UI

## Technologies

* HTML
* CSS
* JavaScript

**Note:** PetNesto is a frontend-only project, and this repository contains the Accessories Page feature implemented for the project.
